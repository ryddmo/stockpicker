- (direction) Coaching path. Spine ar enda leveransen; syfte = build substrate / grund for utveckling. Ensam lasare/byggare (Stefan). Indata: brief.md + addendum.md (K1-K12), ingen SPEC.md.
- (constraint) Anvandaren vill hosta pa sin Loopia. Loopia delat webbhotell (research 2026-09-08): Python endast via CGI i cgi-bin (3.11), PHP 8.x + MySQL ar forstaklass. Cron = HTTP GET mot URL, inte shell; intervall bara 5 min / dagligen 00:00 / veckovis - EJ valfri tid. En instans i taget. Delat webbhotell har typ exekveringstidsgranser som krockar med ~1000 instrument x 2 kallor x snall rate-limit (500-1000+ s).
- (decision) Stack: PHP 8 + MariaDB pa Loopia delat Unix-webbhotell (Privatpaket). Binder hela v1. Forhindrar: att bygga i en runtime plattformen inte stodjer forstaklass (Python bara via CGI). Nattjobb = cron-triggad skyddad URL-endpoint. Ingen pyavanza - adaptrar reimplementeras i PHP (enkla GET-anrop).
- (decision) Dataagande [ADOPTED av anvandaren]: instrument-tabellen skrivs bara av universum-avstamningen (Borsdata-adaptern). owner_count_daily ar kallindelad - varje kalladapter skriver bara sina egna source-rader. Harledda matt ar read-only over fakta. Forhindrar: dubbla skribenter pa samma rad, kapplopning mellan kallor.
- (decision) Kor-modell: daglig URL-cron 00:00 fyller en work_queue-tabell for dagens instrument; 5-min URL-cron kor en tidsboxad worker (~60-90s) som claimar kojobb atomiskt (UPDATE...WHERE status=pending...LIMIT n) och avslutar rent, upprepat tills kon ar tom. K3 kor-inte-fore-tid = installningsrad. Forhindrar: overskriden exekveringstid, dubbelclaim vid overlappande cron.
- (decision) Paradigm: pipes-and-filters. Steg: universe-sync -> enqueue -> fetch(per kalla) -> normalize -> upsert -> derive. Kalladaptrar bakom gemensamt SourceAdapter-interface; pipeline-karnan kanner aldrig HTTP/endpoint-egenheter.
- (decision) Adapterkontrakt: fetch-adapter returnerar normaliserad rad {isin,source,as_of_date,number_of_owners,last_price,market_cap,fetched_at} ELLER typat fel (SchemaMismatch/NotFound/Transient). Karnan agerar bara pa typerna. K9 schemakoll bor i adaptern; SchemaMismatch loggas, korningen fortsatter.
- (decision) Beroenden via Composer, inget ramverk: Guzzle (HTTP), rak PDO (ingen ORM), Phinx (migrationer), Monolog (logg). public_html/ har tunn front controller for cron-endpoints + senare UI.
- (decision) Konfig: config.php utanfor public_html (DB-uppgifter, cron-token). Operativa parametrar (kor-efter-tid, batchstorlek, req/s) i settings-tabell - justeras utan deploy.
- (decision) Katalogseed: stockpicker/{public_html,src/{Adapter,Pipeline,Store},bin,db/migrations,config.php,vendor}
